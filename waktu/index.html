Kalkulator apa ini?
Kalkulator ini digunakan untuk menghitung waktu. Misalnya 100 jam dari sekarang itu jam berapa, atau 18391261 detik dari sekarang itu jam berapa, dsb. Semua perhitungan dilakukan oleh Python bukan JS (Javascript)

Note: Ini adalah project pribadi

Project ini untuk menguji interpreter Python di lingkungan web tanpa server, dengan memanfaatkan Web Assembly
