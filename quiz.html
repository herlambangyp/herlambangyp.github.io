Cara Buat Data Quiz
1. Format data kotoba/kosakata
  • Format = "Soal (arti, furigana/cara baca)"
  • Beberapa bagian dikosongkan tidak masalah.. Seperti bagian furigana misalnya (Jika soalnya tidak memiliki kanji)
  • Format data cocok untuk semua mode quiz (Fitur "custom-file.qs" yg akan diupdate)
  • Contoh penulisan yang tepat:
    • ことば(kosakata),<-tiap kata tutup dg koma
    • 長い (panjang, ながい),
    • 辞書 (kamus,じしょ),
    • チョコレート(coklat),
2. Format data huruf
  • Format = Huruf Jepang (huruf latin diabaikan)
  • Jgn gunakan koma "," atau dalam kurung "( )"
  • Format ini hanya untuk mode quiz menulis
  • Furigana/Cara baca akan diisi otomatis oleh sistem quiz
  • Contoh penulisan yang tepat:
    • あい うえお
    • 一二三四五六 七八九 十百千 万
