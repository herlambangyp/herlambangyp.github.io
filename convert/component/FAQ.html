Menggunakan sistem virtual Python
Web ini akan membuat semacam "Sistem Virtual" untuk menjalankan Python. Sistem ini berjalan sepenuhnya diperangkatmu. Tenang, ini tidak menggunakan penyimpanan sama sekali. Saat kamu tutup web ini, seluruh sistem virtual akan terhapus dan dihancurkan

  • Spesifikasi Minimum Perangkat
  • RAM: 512MB
  • CPU: Single-core 1 GHz
  • GPU: Dedicated / Bawaan (tidak diperlukan)
  • Penyimpanan: Minimal tersedia 2x ukuran dokumen yang diupload
  • Bencmark: Perangkat dengan spesifikasi diatas memakan waktu 2 menit dalam memproses PDF dengan 20 Halaman (DPI:150 Quality: 85%)
